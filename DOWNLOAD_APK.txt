LANGKAH 1: Download Source Code
   → File: AutoLinkOpener.zip
   → Lokasi: /vercel/sandbox/AutoLinkOpener.zip

LANGKAH 2: Extract ZIP
   → unzip AutoLinkOpener.zip

LANGKAH 3: Buka di Android Studio
   → File → Open → Pilih folder AutoLinkOpener
   → Tunggu Gradle sync selesai

LANGKAH 4: Build APK
   → Build → Build Bundle(s) / APK(s) → Build APK(s)
   → Atau via terminal: ./gradlew assembleDebug

LANGKAH 5: Install di HP Android
   → APK ada di: app/build/outputs/apk/debug/app-debug.apk
   → Transfer ke HP dan install
